# MigrationPilot Homebrew tap

```bash
brew install mickelsamuel/migrationpilot/migrationpilot
```

[MigrationPilot](https://migrationpilot.dev) blocks unsafe PostgreSQL migrations before merge — 112 rules, the real Postgres parser, lock analysis, auto-fix. The formula installs the npm package and needs Node.

Source: https://github.com/mickelsamuel/migrationpilot
